# homebrew-tap

Homebrew tap for [`codegraph`](https://github.com/seanb4t/codegraph-go) — a
pre-indexed code knowledge graph for coding agents.

Casks in this tap are published automatically by
[`seanb4t/codegraph-go`](https://github.com/seanb4t/codegraph-go)'s release
pipeline. See that repository for installation instructions and documentation.

## Formulae

- `pam-watchid`: hand-maintained, built from source from
  [`seanb4t/pam-watchid`](https://github.com/seanb4t/pam-watchid), a hardened
  fork of the Apple Watch PAM module. Read the caveats before wiring it into
  PAM: sudo must load a root-owned copy, not the Homebrew one.
